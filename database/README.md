# Database Scripts

This directory contains the SQL scripts for the Enterprise Library Management System database.

## Scripts

- `01_create_database_and_user.sql` — Creates the database and database user.
- `02_schema.sql` — Creates the database tables and relationships.
- `03_reset_loans_only.sql` — Resets loan-related records.
- `04_reset_everything.sql` — Resets the database data.

## Usage

Review each SQL script before execution. Run the scripts in the correct order and configure database credentials securely for your environment.
